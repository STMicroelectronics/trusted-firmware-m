stm32mp257f ev1 copro:

Build

$ cmake -S <SRC_DIRECTORY> -B <BUILD_DIRECTORY> \
-DTFM_PLATFORM=stm/stm32mp257f_ev1 \
-DTFM_TOOLCHAIN_FILE=toolchain_GNUARM.cmake \
-DTFM_PROFILE=profile_medium \
-DCMAKE_BUILD_TYPE=Relwithdebinfo
$ make -C <BUILD_DIRECTORY> install

Remoteproc loading:

Refer to remoteproc part to: concataned secure and no-secure binaries, sign and load the firmware.

stm32mp257f ev1 m33tdcid:

Build

$ cmake -S <SRC_DIRECTORY> -B <BUILD_DIRECTORY>
-DTFM_PLATFORM=stm/stm32mp257f_ev1 \
-DTFM_TOOLCHAIN_FILE=toolchain_GNUARM.cmake \
-DTFM_PROFILE=profile_medium \
-DSTM32_M33TDCID=ON \
-DCMAKE_BUILD_TYPE=Relwithdebinfo
$ make -C <BUILD_DIRECTORY> install

Boot device

bl2 may boot on (bl2 dt file must be aligned):

  • default, serial nor (ospi): -DSTM32_BOOT_DEV=ospi
  • sdcard (sdmmc1): -DSTM32_BOOT_DEV=sdmmc1
  • emmc (sdmmc2): -DSTM32_BOOT_DEV=sdmmc2

Notes:

if you would use external device tree for your components (BL2 | S | NS) add these flags on cmake command:
  • -DDTS_EXT_DIR=<external_dt_path>
  • -DDTS_BOARD_S=<dts_file_secure>
  • -DDTS_BOARD_NS=<dts_file_non_secure>
  • -DDTS_BOARD_BL2=<dts_file_bl2>
In m33tdcid, CortexA must be started by Non secure firmware with specific CPU service.
You can find an example in internal tf-m-test file: main_ns.c function: tfm_ns_start_copro
If you would use your own NS firmware, add this flag on cmake command:
  • -DNS=FALSE
If you build with tfm ns firmware (default configuration), you must use stm32 tf-m-tests repository:
  • ssh://gerrit.st.com:29418/mpu/oe/st/TF-M/tf-m-tests
  • branch : v1.7.0-stm32mp25-alpha-w2450
  • tag: v1.7.0-stm32mp25-alpha-r1-rc3
clone stm32 tf-m-tests repository, add this flag on cmake command:
  • -DTFM_TEST_REPO_PATH=<tf-m-tests_path>
In copro mode, the spi nor must be defined for m33 => used optee external device tree (ostl)
